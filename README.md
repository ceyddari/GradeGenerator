# GradeGenerator

This is a simple Python project that:

- Loads student names and ages from a CSV file
- Assigns 3 random grades (between 50 and 100) to each student
- Calculates their average
- Filters out successful students (average ≥ 70)
- Includes an object-oriented `Student` class example

## How to Run

1. Make sure you have `students.csv` in the same directory.
2. Run the project:

```bash
python main.py

Requirements
Python 3.7+

No external libraries required
